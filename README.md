One original one-line joke about cats, written by a program. The joke: a cat
leaves dead mice on its owner's pillow — not as a gift, but as a performance
review, and the human is the one underperforming. A familiar cat behaviour with
a late turn that flips who is judging whom.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the joke deterministically to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), self-checks the gate (one line, 1–200
characters by code-point count, no control characters, no edge whitespace),
reads it back with strict UTF-8 decoding and verifies it byte-for-byte.
